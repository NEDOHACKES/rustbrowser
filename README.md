# RustBrowser

Rust-first browser project inspired by Chromium architecture.

## Goal

Build a browser in Rust incrementally, replacing browser subsystems with Rust implementations instead of mechanically translating the entire Chromium C++ tree.

## Initial architecture

- Browser shell
- Window
- Tabs
- Navigation
- Network (planned)
- Renderer (planned)
- IPC (planned)
- GPU (planned)
- Sandbox (planned)

## Development

```bash
cargo run
```
